### 一、项目基本信息（已确认）
- **服务对象**：尼泊尔蓝毗尼的**中华寺**。
- **立意主线**：以**普贤十大愿王**为引领，展开在中华寺的共修生活。十个体验项目 = 一天时间轴（踏进寺门 → 一天生活 → 结束）。
- **诞生背景**：中华寺是**本焕长老法脉传承之地**，本焕长老生前留下普贤菩萨行愿品的**血经**；《普贤行愿品》是汉传大乘佛教最根本的教义与修行法门。中华寺有很多挂单游客，寺方希望游客循着《普贤行愿品》体验寺里每一项生活。
  - 设计时要融入三个核心元素：**血经 / 行愿 / 蓝毗尼圣地**。
  - 背景已通过 WebSearch 核实：中华寺确为本焕长老法脉、血经《普贤行愿品》传承地，僧众在圣园诵此经的传统有记载。
- **用途**：免费发给游客，印制数量无需考虑。
- **形态**：**奏折式展开折页**（像古代奏折/经折装那样一折一折来回折叠展开的长卷，不是骑马钉小册子），内容约 **12–13 页**。此形态已于 2026-11-27 用户亲口确认，不再问。
- **交付顺序**：先电子版 → 定稿前全程需要**每一个组件模块都可编辑**的版本 → 最终纸质手册。
- **素材**：用户手里有照片；**航拍平面图**希望 AI 在照片基础上生成**手绘风格版本**；手册要放一张**导览图**（即该航拍俯视图的手绘版）。
- **用户画像**：设计/编程小白，所有操作步骤必须逐步、保姆级指引。

### 二、十个体验项目（清单已定，文案待雕琢）
引言原文：「以普贤十大愿王为引领展开在中华寺的共修生活。如来佛的功德，无边无际、不可穷尽，若欲成就此功德门，应修十种广大行愿。」

1. **礼敬诸佛** — 迈进中华寺大门后，每一刻抱持恭敬之心，礼敬每一尊佛像，面对每一个来往的法师、居士、游客。地点：寺里每一处。
2. **称赞如来** — 晨起准时上殿参加早课，绕佛，念佛号千百遍。地点：大雄宝殿。
3. **广修供养** — 早上出坡，山门散香、大雄宝殿帮助游客点酥油灯。地点：山门 / 大雄宝殿。
4. **忏悔业障** — 上晚课，其中大忏悔文部分即沉浸式忏悔业障。地点：大雄宝殿。
5. **随喜功德** — 供养寺院、捐钱。地点：大雄宝殿、斋堂、茶寮。
6. **请转法轮** — 请某位跟你有缘的师傅聊天喝茶、请教问题。地点：任何地点，大胆开麦。
7. **请佛住世** — 掉落的彩蛋：若恰逢周天朝圣日，可随寺里法师前往释迦牟尼佛出生地朝圣，感谢佛陀降世开示，祈愿高僧大德长久住世。地点：圣园。
8. **常随佛学** — 晚七点到禅堂坐香：数息、随息、四念处、观呼吸、参话头，随佛教法而行，回家后亦可常随佛学。地点：禅堂。
9. **恒顺众生** — 做义工，身体力行做服务，把自己摒弃掉，满足别人的愿望/需要，由此改变自己、不改变任何人，好的坏的都随顺，随顺因缘。地点：客堂统一安排 / 寺里偶遇。
10. **普皆回向** — 在茶寮写一个回向心愿卡，回向给家人、亲人，或特别恨的人。地点：茶寮。
